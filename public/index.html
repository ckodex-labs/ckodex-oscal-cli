NIST Parity & Modern Tooling CLI Reference

Full drop-in parity with NIST oscal-cli plus advanced extensions for 3-way AST merge, blast radius analysis, and derogation leasing.

# 1. Official OSCAL Metaschema Validation mizan validate path/to/catalog.json --strict mizan catalog validate path/to/catalog.json # 2. Universal AST Format Converter (JSON, YAML, CSV Compliance Matrix, Protobuf) mizan convert input.json --to=yaml -o output.yaml mizan convert input.json --to=csv -o matrix.csv mizan convert matrix.csv --to=json -o output.json mizan convert input.json --to=proto -o output.pb # 3. 3-Way GitOps AST Synchronization & Reconciler mizan sync --base base.json --upstream upstream.json --local local.json -o merged.json # 4. Multi-Model Blast Radius Impact Analysis mizan blast-radius path/to/ssp.json --target ac-1 --context path/to/catalog.json # 5. Time-Bounded Cryptographic Derogation Leases (Pipeline Waivers) mizan waive create --rule cis-k8s-5.2.1 --resource deploy.yaml --duration-days 30 mizan waive list # 6. shieldcn-zig Pure-Zig Badge Generator (APCA WCAG 3.0 Mode) mizan export badge --label "FedRAMP" --message "Moderate COMPLIANT" --color green --variant secondary --wcag 3 # 7. Standalone Zero-Install Offline Cryptographic Evidence Capsule mizan export capsule -a assessment-results.json -o capsule.html
